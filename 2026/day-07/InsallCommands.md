# Day 07 – Linux Package Installer: Apt, Yum, Rpm

This are the package managment commands used to install,update, and remove softwares,


apt (Advanced Package Tool): Used in Debian-based systems, including Ubuntu, Linux Mint, and Debian itself.
yum (Yellowdog Updater, Modified): Primarily used in Red Hat Enterprise Linux (RHEL), CentOS, and Fedora systems (though Fedora now uses dnf, a successor to yum).
rpm (Red Hat Package Manager): low-level command for Red Hat-based systems. 


sudo apt install nginx
sudo apt remove nginx
sudo apt update
sudo apt upgrade
apt search
